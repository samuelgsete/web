DESENVOLVIMENTO WEB I

Turma [DDW-2602]

Ementa do curso

[De 13/10/2026 à 05/11/2026] · [40 horas] · [Presencial]

Objetivo

Introduzir os participantes ao desenvolvimento front-end, capacitando-os a construir páginas Web completas e interativas com HTML, CSS e JavaScript: estruturar conteúdos com tags semânticas, listas, links, mídias, tabelas e formulários; estilizar e organizar o layout com CSS, Box Model e Flexbox; e dar comportamento às páginas com variáveis, funções, eventos e manipulação do DOM.

Ferramentas

Visual Studio Code, Google Chrome, Git e Github

Conteúdo programático

  • 01

    Fundamentos da Web

    Tecnologias por trás de uma página Web e arquitetura cliente/servidor. Origem e evolução do HTML. Noções de programação e anatomia básica de um documento HTML.

  • 02

    Tags de texto e listas

    Tags de título e parágrafo, formatação de texto com negrito, itálico e sublinhado, e criação de listas ordenadas e não ordenadas.

  • 03

    Links, mídias, tabelas e tags semânticas

    Criação de links, inserção de imagens, áudio e vídeo, construção de tabelas e estruturação da página com tags semânticas.

  • 04

    Construindo uma Loja virtual

    Desenvolvimento de uma loja virtual com quatro páginas interligadas, aplicando navegação entre páginas, imagens, tags de texto e tabelas na organização dos produtos e do carrinho de compras.

  • 05

    Formulários

    A tag form e seus atributos, campos de entrada de dados (texto, senha e seleção), botões e envio de formulários.

  • 06

    Introdução ao CSS

    Origem e evolução do CSS. Conceito e finalidades do CSS. Formas de aplicação do CSS (inline, interno e externo), sintaxe, primeiras regras CSS.

  • 07

    Seletores e paleta de cores

    Seleção de elementos com CSS e os principais tipos de seletores: universal, de tag, de ID, de classe, de filho direto e de descendente. Definição de cores por nome, RGB e hexadecimal, com o seletor de cores do Visual Studio Code.

  • 08

    Box Model, altura, largura e cor de fundo

    Modelo de caixa (conteúdo, padding, borda e margin), outline, dimensionamento de elementos e aplicação de cor de fundo.

  • 09

    Posicionando elementos com Flexbox

    Display block e inline, contêiner e itens flexíveis, direção dos eixos, alinhamento, responsividade e distribuição dos itens e espaçamento entre eles.

  • 10

    Estilizando telas de login e cadastro

    Formatação de textos: tamanho, peso, cor, alinhamento e espaçamento. Organização do CSS em arquivos com @import e uso de variáveis CSS. Ícones e fontes do Google. Transições suaves. Construção de dois formulários completos, com os estados hover, focus e disabled.

  • 11

    Noções de JavaScript

    O que é a linguagem e como ela é executada no navegador. Inclusão de scripts em páginas HTML. Variáveis, tipos de dados e operadores aritméticos e de comparação. Estruturas condicionais com if/else e switch/case. Funções. Seleção de elementos HTML pelo DOM.

  • 12

    Implementação do projeto final - Parte I

    Planejamento e início do projeto final da turma: definição das páginas e funcionalidades, criação da estrutura HTML e dos primeiros estilos.

  • 13

    Implementação do projeto final - Parte II

    Conclusão do projeto final: implementação das funcionalidades com JavaScript, ajustes de layout, testes e apresentação dos resultados.

  • 14

    Apresentação do projeto final

    Apresentação dos projetos pelos alunos, devolutiva do professor e encerramento do curso.
